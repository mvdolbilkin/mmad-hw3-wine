# Винная подборка — ДЗ-3

Приложение оценивает вероятность того, что качество вина не ниже 7.
Пайплайн `StandardScaler + LogisticRegression` обучен в `../HW3_MMDA.ipynb`.
В приложении модель не переобучается.

## Запуск

Python **3.13.2**, версии библиотек указаны в `requirements.txt`.
Из папки `wine_app`:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows активация окружения: `.venv\Scripts\activate`.
Откройте адрес, который выведет Streamlit.
Рядом с `app.py` должны лежать `model.joblib`, `config.json` и `test.csv`.

## Использование

В приложении четыре вкладки: оценка одного вина, метрики модели,
пакетный прогноз по CSV и коэффициенты модели. Общий порог задаётся
в сайдбаре; начальное значение берётся из `config.json`.

Пример CSV можно скачать на вкладке пакетного предсказания.
Нужны 12 признаков без `target`; `is_red`: 0 — белое вино, 1 — красное.
Разделитель — запятая, десятичный знак — точка. Результат можно скачать.

## Кэширование — задание 4.5

Для модели используется `st.cache_resource`: при повторных запусках скрипта
возвращается один и тот же объект. Для таблиц и вероятностей используется
`st.cache_data`: результат сохраняется в кэше, а при обращении возвращается копия.
Вероятности не зависят от порога, поэтому при движении слайдера
пересчитываются только метки и метрики.

Без декоратора `joblib.load` заново читал бы и десериализовывал модель
при каждом перезапуске скрипта, в том числе при изменении порога.
После замены файлов модели или данных нужно очистить кэш либо перезапустить сервер.
